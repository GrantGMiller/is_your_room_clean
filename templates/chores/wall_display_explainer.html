Wall Display

Set up a shared chore screen

Open the Wall Display on a parent device, then share its secure link with a child or another browser.

1

On the parent device, open Wall Display

Go to the chores overview and select Open wall display. The page that opens contains a QR code and a link for the shared device.

2

Open it on the child's device

Use the child's device or any device with a web browser. It does not need to be logged in as the parent.

3

Scan the QR code or enter the link

On the parent device's Wall Display page, scan the QR code with the child device's camera. If scanning is not available, type the address shown on that page into the browser instead. The link is specific to your shared display, so share it only with people who should access the chores.

4

Check chores off on the shared screen

The child can choose their name, view assigned chores, and mark chores done. The Wall Display is limited: it cannot add, edit, or remove chores or people, and it cannot access parent settings.
