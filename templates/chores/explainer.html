Getting started

A simple guide to chores

Add people, set up repeating chores, and use tags to switch groups of chores on or off.

In this guide

1. Add people 2. Set schedules 3. Add a tag 4. Pause tagged chores
1

Add at least two people

From the chores overview, choose Add person. Enter a name, optionally choose a color or starting {{ money_name }}, then select Save New Person. Repeat for each person in your household.

2

Create repeating chores

Select Add chore, enter a name, and choose Repeat. Configure the interval and time of day, then continue to choose who can be assigned the chore.

Daily

Clean room

  1. Name: Clean room
  2. Choose Repeat and Daily.
  3. Choose Evening.
  4. Continue and select the people for this chore.
Weekly

Take out trash

  1. Name: Take out trash
  2. Choose Repeat and Weekly.
  3. Select Tuesday and Afternoon.
  4. Continue and select the people for this chore.
Monthly

Replace water filter

  1. Name: Replace water filter
  2. Choose Repeat.
  3. Choose Another interval.
  4. Set Every 1 month, then continue and assign it.

3

Add a tag such as “school”

After creating a chore, open it from the overview to edit it. Find Tags, type school, and press Enter. Save the chore. Add the same tag to each chore you want to manage together.

4

Pause school chores for a break

On the chores overview, choose Tag Manager. Find school and select DISABLE ALL when holiday break starts. The tagged chores are disabled and unassigned. When school resumes, choose ENABLE ALL for that tag to enable the chores again.
