Using the API

Include your API key in the X-API-KEY header with every request.

Returns the devices connected to your account.

curl "{{ base_url }}api/get_devices" \
  -H "X-API-KEY: YOUR_API_KEY"

Replace DEVICE_ID with an ID from the devices response.

curl "{{ base_url }}api/get_snapshot/DEVICE_ID" \
  -H "X-API-KEY: YOUR_API_KEY" \
  --output snapshot.jpg

Replace DEVICE_ID with an ID from the devices response.

import requests

response = requests.get(
    "{{ base_url }}api/get_summary/DEVICE_ID",
    headers={"X-API-KEY": "YOUR_API_KEY"},
)
response.raise_for_status()
summary = response.json()
